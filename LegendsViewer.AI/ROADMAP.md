# Roadmap

## Исследование графа сущностей

1. **Статистика ссылок в XML**  
   Собрать статистику по ссылкам внутри XML: найти все ссылочные элементы для разных сущностей.

2. **Связи между сущностями**  
   Выяснить, как связаны сущности, и определить важность связей.

3. **Глубина обхода**  
   На основании пунктов 1 и 2 определить максимальное число переходов, которое даёт максимум полезного результата при минимуме затрат токенов.

## Фильтрация и guardrails

4. **Guardrails по важности событий**  
   Подготовить guardrails, чтобы пропускать только важные события (возможно, через субагентов).  
   Под каждую сущность расписать критерии «крутости» и интересности.
